# AMUECI Gestion Frontend

Frontend `Next.js` para la primera version de la aplicacion de gestion de la asociacion musical.

## Incluye

- Login protegido
- Dashboard resumen
- Gestion de vestimentas
- Gestion de instrumentos
- Paginas agregadas para prestamos, lavados y reparaciones
- Vistas de detalle por vestimenta e instrumento

## Requisitos

- Node 22+
- npm 10+

## Variables

```bash
NEXT_PUBLIC_API_URL=http://localhost:8080
```

## Arranque rapido

```bash
npm install
npm run dev
```

La aplicacion quedara en `http://localhost:3000`.
